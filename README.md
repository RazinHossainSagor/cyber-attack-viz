# Cybersecurity Attack Visualization

## Project Overview

A 3D web-based project that simulates network traffic and visualizes network devices, connections, and potential threats in an interactive environment.

**Note:** All traffic and attack alerts are simulated. This project does not detect real-world cyberattacks.

## Features

- Interactive 3D network visualization
- Normal, suspicious, and malicious traffic simulation
- Live traffic counters and activity logs
- Malicious traffic alerts
- Color-coded device status
- Device information on hover and click
- Pause and Play controls
- 3D camera navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js

## How to Run

1. Open the project folder in Visual Studio Code.
2. Run the project using the development server configured for your setup.
3. Open the local URL provided by the server in your browser.
